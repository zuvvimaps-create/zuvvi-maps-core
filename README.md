# Zuvvi Maps Core

Create 'Zuvvi Maps', a premium, modern, mobile-first mapping web app and installable PWA with an enterprise-grade reusable design system.

Key requirements:
1. Architecture & Setup:
   - Clean modular architecture: /components (ui, layout, map), /pages, /hooks, /services, /utils, /types, /theme.
   - PWA configuration (manifest, responsive meta tags, theme colors).
   - Light and dark mode support with accessible contrast and smooth transitions.

2. 'Zuvvi Maps' Design System & Tokens:
   - High-end tech startup aesthetics: sleek dark surfaces, precision borders, refined shadows, neon/emerald/cyan accent glow accents or premium royal sapphire/violet tones, crisp modern sans typography.
   - Centralized design tokens (color palette, spacing, radii, typography scales, elevation shadows).
   - Component system: buttons with all variants & loading states, inputs, elevated cards, dialog modals, mobile bottom sheets, search/filter chips, and navigation headers.

3. Core Experience & Showcase:
   - Main layout with responsive header, floating search bar, layer toggles, and mobile bottom navigation.
   - Interactive map landing view featuring a spatial preview, search overlay, location drawer / bottom sheet with place details, quick actions, and filter tags.
   - Component showcase / design system guide explaining tokens, component usage, and architecture.
